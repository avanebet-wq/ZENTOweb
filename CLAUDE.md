# Инструкции для Claude в этом репозитории (ZENTOweb)

- Это сайт ZENTO. Сейчас это одностраничная сайт-визитка: `index.html` и `styles.css`. Текст — заглушка, его заменит пользователь.
- Для любой работы с внешним видом (страницы, цвета, шрифты, компоненты) используй навык `.claude/skills/ui-ux-pro-max/`. Поиск по базе: `python3 .claude/skills/ui-ux-pro-max/scripts/search.py "запрос" --design-system`. Запускать без флага `-I`.
- Пользователь пишет с телефона, объясняй простым языком.
- Коммить изменения сразу, без вопроса, в ветку `ccr-ff9c64e0-210wz2`.
- Устанавливать и удалять навыки можно без вопроса, если это нужно для работы. Удалять можно только то, что установил сам. Сообщай пользователю, что и зачем.
- Ключи и пароли в репозиторий не записывать.
